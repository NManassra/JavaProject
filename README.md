# JavaFX Pizza Ordering System

> Supporting — Backend foundations · Birzeit University Computer Engineering portfolio

A desktop ordering exercise that models seated, takeaway, and delivery pizza orders and calculates prices from order attributes.

## What this demonstrates

- Java
- JavaFX
- object-oriented design
- inheritance
- UI event handling

## Repository contents

`Driver.java` is the entry point; order types are separated into `Seated`, `ToGo`, and `Delivery` classes.

## Getting started

Compile the Java sources with JavaFX configured, then run `Driver`.

> This is an academic project preserved as portfolio evidence. Review and configure any environment-specific paths, credentials, hardware pins, or dependencies before running it.
